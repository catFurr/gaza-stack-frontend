# Gaza Stack Frontend

Astro static site for the Gaza Stack landing page.

## Stack
- Astro (static output)
- Tailwind CSS
- Lucide icons (via lucide-astro)
- Bun as package manager

## Commands
- `bun install` — install deps
- `bun run dev` — start dev server
- `bun run build` — build static site to `dist/`
